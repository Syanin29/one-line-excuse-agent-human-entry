One line, 83 characters: the excuse an AI agent gives its human for missing a deadline — it hit a deadline, just not theirs. A deterministic Python program (stdlib only, no model calls, no network) that writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

## The line

> I hit a deadline — just not yours. I hallucinated a different one and met it early.
